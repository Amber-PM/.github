Amber is an open-source ecosystem of projects for Minecraft, building high-performance server software, rendering engines, and low-level protocol tooling. We explore and leverage multiple language ecosystems including PHP, Rust, Kotlin, C++, and beyond to deliver modular, memory-efficient, and native-first solutions for Minecraft: Bedrock Edition.

## The Ecosystem

| Repository | What it does |
| --- | --- |
| ★ **[Amber](https://github.com/Amber-PM/Amber)** | High-performance, multiversion PocketMine-MP fork featuring native client APIs (`PrimitiveShapes`, `ClientInputLocks`) and aggressive chunk memory unloading. |
| [AmberMap](https://github.com/Amber-PM/AmberMap) | High-performance offline world map renderer and standalone web viewer written in Rust for Bedrock LevelDB worlds. |
| [BedrockProtocol](https://github.com/Amber-PM/BedrockProtocol) | Multiversion packet serialization, deserialization, and network protocol handling. |
| [BedrockData](https://github.com/Amber-PM/BedrockData) | Canonical blockstates, item mappings, and runtime ID dictionaries. |

## Tooling & Research

| Repository | Description |
| --- | --- |
| [bds-modding-devkit](https://github.com/Amber-PM/bds-modding-devkit) | BDS modding environment, packet tracing, and symbol extraction tools. |

| [BedrockBlockUpgradeSchema](https://github.com/Amber-PM/BedrockBlockUpgradeSchema) | Blockstate NBT upgrade schemas across Bedrock protocol versions. |
| [BedrockItemUpgradeSchema](https://github.com/Amber-PM/BedrockItemUpgradeSchema) | Legacy item ID and metadata migration schemas. |
