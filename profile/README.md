Amber is an open-source ecosystem focused on Minecraft: Bedrock Edition server software, multiversion networking, native extensions, world rendering, and protocol tooling.

Our projects span PHP, C++, Rust, and Python, with an emphasis on performance, compatibility, and maintainability.

## The Ecosystem

| Repository | Description |
| --- | --- |
| ★ **[Amber](https://github.com/Amber-PM/Amber)** | Lightweight, feature-rich, multiversion PocketMine-MP fork. |
| [BedrockProtocol](https://github.com/Amber-PM/BedrockProtocol) | Multiversion Bedrock packet serialization and protocol handling. |
| [BedrockData](https://github.com/Amber-PM/BedrockData) | Bedrock blockstates, item mappings, and runtime ID data. |
| [NetherNet](https://github.com/Amber-PM/NetherNet) | Standalone WebRTC transport library for Minecraft: Bedrock Edition, written in PHP. |
| [ext-rtc](https://github.com/Amber-PM/ext-rtc) | Native C++20 WebRTC DataChannels extension for PHP, powered by libdatachannel. |
| [PHP-Binaries](https://github.com/Amber-PM/PHP-Binaries) | PHP build scripts and runtime binaries for PocketMine-compatible servers. |
| [AmberMap](https://github.com/Amber-PM/AmberMap) | High-performance Bedrock world renderer and standalone web viewer written in Rust. |

## Tooling & Research

| Repository | Description |
